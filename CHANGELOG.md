# История изменений

Все заметные изменения VoiceTexter. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация версий — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.4] - 2026-10-14

### Исправлено
- **Обновление программы больше не открывает окно консоли.** Установщик
  (`apply_update.bat`) запускается скрыто (`CREATE_NO_WINDOW`), ожидание выхода
  старой копии ограничено по времени (раньше мог висеть вечно), а приложение
  гарантированно завершает свой процесс перед подменой файлов.
- **Вторая копия приложения больше не запускается.** Раньше приложение только
  показывало предупреждение, но позволяло запустить ещё одну копию — копии делили
  микрофон, хоткей, буфер обмена и `config.json`, а также держали в памяти по
  полной копии модели (лишняя нагрузка на CPU и RAM). Теперь при запуске второй
  копии показывается сообщение и приложение выходит.
- **Распознавание перестало «зацикливаться».** Слишком узкое окно энкодера
  (≤ 12 с) заставляло Whisper повторять фразу целиком — это и портило текст, и
  делало распознавание дольше (лишние токены).

### Изменено
- **«Окно энкодера» по умолчанию 10 → 20 с.** Значения ≤ 12 с ускоряют сильнее,
  но могут вызывать повторы; 20 с даёт чистый текст при ускорении ~1.7×
  относительно штатных 30 с. Сохранённое значение `10` автоматически поднимается
  до `20`.
- Добавлена защита от зацикливания декодера (`no_repeat_ngram_size=3`).

### Добавлено
- `CHANGELOG.md` — этот файл; примечания к релизам теперь берутся из него.

## [1.0.3] - 2026-10-14

### Добавлено
- **Ускорение энкодера на CPU и GPU.** Клип кодируется окном не 30 с, а
  настраиваемым значением («Окно энкодера» в настройках), что заметно снижает
  задержку на коротких фразах. `30` возвращает штатное поведение Whisper.
- **Предупреждение о других запущенных копиях** — вверху окна появляется пометка,
  если рядом уже работает ещё одна копия VoiceTexter (в т.ч. другой версии).

## [1.0.2] - 2026-10-14

### Добавлено
- **Каталог моделей.** Список доступных моделей со статусом, скачивание и
  обновление (дозагрузка только изменившихся файлов), отмена загрузки, выбор
  активной модели кликом по строке.
- **Автообновление программы из GitHub Releases.** Проверка обновлений по кнопке,
  скачивание архива с проверкой `sha256`, распаковка, подмена файлов и
  перезапуск. Модели и `config.json` при обновлении не затрагиваются.

### Исправлено
- Раскладка настроек: выбор устройства (Авто/GPU/CPU), перекрытие выпадающего
  списка микрофонов, единая галочка «через прокси» для разделов «Модели» и
  «Настройки».

## [1.0.1] - 2026-10-14

### Добавлено
- Экран первичной настройки прямо в окне: выбор и загрузка модели с прогрессом,
  без отдельного диалогового окна.

### Исправлено
- Зависание статуса «Загрузка модели…», когда локальных моделей ещё нет — теперь
  показывается «Нет моделей» с предложением скачать.

## [1.0.0] - 2026-10-14

Первый публичный релиз.

### Добавлено
- **Диктовка push-to-talk**: удерживайте сочетание клавиш (или боковую кнопку
  мыши) — идёт запись; отпустите — текст распознаётся и вставляется в активное
  окно.
- **Локальное распознавание** через faster-whisper (модели скачиваются прямо в
  приложении), поддержка CPU и GPU, русского, английского и других языков.
- **Настраиваемые горячие клавиши** (клавиатура и мышь) и способ вставки
  (`Ctrl+V` / `Shift+Insert`), возврат прежнего содержимого буфера обмена.
- **Трей**: крестик сворачивает приложение, быстрые настройки в меню значка.
- Тёмный минималистичный интерфейс, тестовое поле для проверки диктовки,
  опциональный VAD и автоформатирование текста.
- **Портативная сборка** (PyInstaller, onedir) и публикация ZIP в GitHub Releases.
