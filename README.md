# VoiceTexter

> Push-to-talk диктовка в **любое** активное текстовое поле на Windows.
> Удерживайте клавишу (или кнопку мыши) — идёт запись микрофона; отпустили —
> локальная модель **faster-whisper** распознаёт речь и вставляет текст
> (Ctrl+V) туда, где стоит курсор.

Простой GUI на [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter).
Всё работает офлайн, модели лежат в `models/`, разрешён GPU (CUDA) и CPU.

## Возможности

- **Push-to-talk**: пока держите бинд — запись, отпустили — распознавание и вставка.
- **Сворачивается в трей**: крестик окна прячет приложение, а не закрывает его — микрофон слушается дальше, выход через меню значка у часов.
- **Быстрые настройки в трее**: правая кнопка по значку — переключение `GPU/CPU`, точности, модели и языка, пауза, VAD, перезагрузка модели.
- **Аккуратный текст**: первая буква — заглавная, в конце фразы добавляется точка, если её нет.
- **Глобальные горячие клавиши**: работают в любой программе, не только в окне VoiceTexter.
- **Бинд на кнопки мыши**: ЛКМ / ПКМ / СКМ и дополнительные кнопки мыши 4/5 (`x1`/`x2`).
- **Локальное распознавание**: faster-whisper (CTranslate2), без интернета.
- **Модели в `models/`**: `tiny`, `base`, `small`, `large-v3-turbo`.
- **Загрузка моделей прямо из приложения**: «Скачать модель» в Настройках (или
  в меню трея) — с прогрессом и возможностью отмены.
- **Прокси для загрузки**: `http(s)://` или `socks5://` (в т.ч. с логином/паролем).
- **Автоопределение GPU**: при наличии CUDA-драйвера используется GPU (`float16`).
- Вставка через буфер обмена с возможностью вернуть прежнее содержимое.
- Опциональный VAD (отсечение тишины) и добавление пробела в конце.
- Тестовое поле прямо в окне — можно проверить диктовку, не переключаясь в другое приложение.

## Установка

> **Готовая сборка (Windows).** На странице
> [**Releases**](https://github.com/StandarterDF/VoiceTexter/releases) лежит
> `VoiceTexter-<версия>-win64.zip`. Распакуйте и запустите `VoiceTexter.exe` —
> Python не нужен. Модель скачайте прямо из приложения
> (Настройки → «Скачать модель»), при необходимости через прокси.

### Автоматически

**Windows:**
```bat
setup.bat
```

**Linux / macOS:**
```bash
chmod +x setup.sh && ./setup.sh
```

Скрипт создаст `.venv`, установит зависимости и скопирует `config.json.example` → `config.json`.

### Вручную

```bash
python -m venv .venv
# Windows
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# Linux / macOS
./.venv/bin/python -m pip install -r requirements.txt
```

### Модели

Модели лежат в `models/`, по одной папке на модель:

```
models/
  whisper-tiny/            (~75 MB)
  whisper-base/            (~141 MB)
  whisper-small/           (~464 MB)
  whisper-large-v3-turbo/  (~1.5 GB)  ← по умолчанию
```

Каждая папка должна содержать `model.bin`, `config.json`, `tokenizer.json`
и `vocabulary.*`. GUI находит модели автоматически по наличию `model.bin`.

**Скачать модель можно прямо из приложения.** В Настройках есть строка
**«Скачать модель»** — выберите модель в списке и нажмите **⬇**. Загрузка идёт
в фоне с прогрессом; по завершении модель появляется в списке и сразу
загружается. Ту же загрузку можно запустить из трея: **Модель ▸ Скачать модель**.

Доступные для загрузки модели: `tiny`, `base`, `small`, `medium`, `large-v3`,
`large-v3-turbo`, `distil-large-v3`. Уже скачанные в списке не показываются.

> `models/` в `.gitignore` — модели большие и в репозиторий не попадают.
> Готовую сборку можно переносить: модели ищутся рядом с `.exe`.

#### Прокси для загрузки

Если Hugging Face недоступен напрямую (блокировки, CDN), включите галочку
**«Прокси для загрузки моделей»** в Настройках и укажите адрес:

```
http://127.0.0.1:8080
socks5://127.0.0.1:1080
socks5h://user:pass@192.168.0.250:2081
```

Поддерживаются `http`, `https`, `socks5`, `socks5h`, `socks4` (`h` — DNS
резолвится на стороне прокси). Для SOCKS нужен пакет `PySocks` — он уже в
`requirements.txt` и попадает в сборку.

## Запуск

Из исходников:

```bat
start.bat
```

или напрямую:

```bash
.\.venv\Scripts\python.exe main.py
```

Собранный `VoiceTexter.exe` (см. «Сборка EXE») запускается двойным щелчком
и не требует Python:

```bat
dist\VoiceTexter\VoiceTexter.exe
```

### Первый запуск

Если в `models/` ещё нет ни одной модели, приложение сразу откроет окно
**«Скачать модель»**: выберите размер (для начала удобна `small`), при
необходимости включите прокси и нажмите **«Скачать»** — под кнопкой виден
прогресс-бар. Тем же окном можно управлять из главного окна кнопкой
**«⬇ Скачать модель»** и из трея (**Модель ▸ Скачать модель**).
Пока модели нет, статус так и пишет «Нет моделей», а не «Загрузка».

### Трей

Крестик окна **сворачивает приложение в трей** — оно продолжает слушать
микрофон и вставлять текст. Значок у часов открывает меню (правая кнопка):

- **Открыть окно** (или двойной клик по значку) — показать окно снова;
- **Поставить на паузу / Возобновить прослушивание** — как кнопка в окне;
- **Устройство** ▸ `Авто` / `GPU (CUDA)` / `CPU` — переключение и сразу
  перезагрузка модели (то же, что «Устройство» в настройках окна);
- **Точность** ▸ `Авто` / `float16` / `int8_float16` / `int8` / `float32`;
- **Модель** ▸ список моделей из `models/` и пункт **Скачать модель** ▸ — загрузка
  отсутствующих моделей с Hugging Face (с прогрессом в журнале);
- **Язык** ▸ `Русский` / `English` / `Авто`;
- **Вставлять текст автоматически** — галочка;
- **Отсекать тишину (VAD)** — галочка;
- **Перезагрузить модель** — перечитать модель текущими настройками;
- **Выход** — полностью закрыть приложение.

Быстрые настройки меняют те же значения, что и элементы в окне, и сразу
сохраняются в `config.json`. Смена устройства/модели из трея всегда
перезагружает модель — удобно быстро переключиться на CPU, не открывая окно.

Отключить это можно галочкой «Сворачивать в трей при закрытии окна» в
Настройках — тогда крестик закрывает приложение, как раньше. Галочка
«Запускать сразу свёрнутым в трей» прячет окно при старте (удобно вместе с
автозапуском).

## Сборка EXE

```bat
build_exe.bat
```

Скрипт сам поставит PyInstaller в `.venv`, сгенерирует значок, соберёт
приложение и подготовит рабочую папку:

```
dist/
  VoiceTexter/
    VoiceTexter.exe      <- запускать это
    _internal/           <- библиотеки, не трогать
    models/              <- ссылка на models\ проекта (или копия)
    config.json
```

Готовую папку можно переносить целиком. `models/` и `config.json` приложение
ищет **рядом с .exe** (а не внутри архива), поэтому настройки и модели можно
менять без пересборки.

Однофайловая сборка (один `VoiceTexter.exe`, ~250 МБ, стартует дольше —
распаковывается во временную папку):

```bat
build_exe.bat onefile
```

Тонкости:

- `models/` в собранной папке — это junction на `models\` проекта. Если
  переносите папку, положите `models/` рядом с `VoiceTexter.exe` вручную
  (или скопируйте).
- Сборка берёт системную среду Visual C++ (`C:\Windows\System32`): старые
  `msvcp140.dll`/`vcruntime140.dll`, которые кладёт установщик Python,
  ломают `onnxruntime` (падение `0xC0000005` прямо на импорте).
- Отладочная консольная сборка с traceback'ами: `set VOICETEXTER_CONSOLE=1`
  перед запуском PyInstaller.

### Архив для релиза

После сборки можно собрать переносимый архив (модели и личный `config.json` в
него **не** попадают — модель качается из приложения):

```bat
make_release.bat
```

Получится `dist\VoiceTexter-<версия>-win64.zip` — его прикладывают к GitHub
Release. Версия берётся из git-тега (`v1.2.3`), иначе из
`packaging/version_info.txt`.

То же самое автоматически делает GitHub Actions
(`.github/workflows/release.yml`): достаточно запушить тег — и появится Release
с собранным архивом:

```bat
git tag v1.0.0
git push origin v1.0.0
```

Пользователю достаточно распаковать архив, запустить `VoiceTexter.exe` и при
необходимости скачать модель в Настройках → «Скачать модель».

## Использование

1. Дождитесь статуса **«Готов · модель …»** (модель грузится в фоне при старте).
2. Поставьте курсор в нужное поле (в браузере, редакторе, мессенджере — где угодно).
3. **Удерживайте бинд** (по умолчанию `Ctrl + Alt + Space`) — в шапке загорится
   «● Запись…».
4. **Отпустите** — текст распознается и вставится в активное поле.

Чтобы сменить бинд: в разделе «Горячая клавиша» нажмите **«Забиндить»**, затем
нажмите нужную клавишу (можно с модификаторами) или кнопку мыши.

### Оформление текста

Перед вставкой фраза приводится к аккуратному виду:

- **первая буква — заглавная** (даже если фраза начинается с кавычки или скобки);
- **в конце ставится точка**, если там нет знака препинания
  (`?`, `!`, `…`, `:` и т.п. — уже считаются завершением).

Пример: `привет как дела` → `Привет как дела.`

### Кнопки мыши

В биндинге поддерживаются:

| Кнопка | Отображение |
|---|---|
| Левая | ЛКМ |
| Средняя | СКМ |
| Правая | ПКМ |
| Мышь 4 (назад) | Мышь 4 |
| Мышь 5 (вперёд) | Мышь 5 |

> Биндить ЛКМ/ПКМ не рекомендуется: они используются в обычной работе.

### Тестовое поле

В окне есть поле «Тестовое поле» — кликните в него и продиктуйте, чтобы
проверить работу, не переключаясь в другое приложение.

## Настройки

Часть настроек меняется прямо в GUI и сохраняется в `config.json`:

| Параметр | Значения | Описание |
|---|---|---|
| Модель | `whisper-*` | Какая модель из `models/` используется |
| Скачать модель | список + кнопка ⬇ | Загрузить модель с Hugging Face (⚙ прогресс, ✕ отмена) |
| Прокси для загрузки | URL | `http://…`, `socks5://…` и т.п. для скачивания моделей |
| Устройство | `auto` / `cuda` / `cpu` | `auto` → GPU при наличии CUDA |
| Точность | `auto`, `float16`, `int8_float16`, `int8`, `float32` | `auto` → `float16` на GPU, `int8` на CPU |
| Язык | `ru` / `en` / `auto` | Язык распознавания |
| Поиск (beam) | `1` / `3` / `5` | Beam search: 1 — быстрее, 3–5 — точнее |
| Вставка | `Ctrl+V` / `Shift+Insert` | Способ вставки в активное окно |
| Начальный промпт | текст | Образец речи для смешанных языков и терминов |
| Устройство ввода | список микрофонов | Какой микрофон слушать |
| Бинд | клавиша/кнопка | Push-to-talk |
| Автовставка | вкл/выкл | Вставлять текст через Ctrl+V |
| Возврат буфера | вкл/выкл | Вернуть прежнее содержимое буфера после вставки |
| Пробел в конце | вкл/выкл | Добавлять пробел после вставленного текста |
| VAD | вкл/выкл | Отсекать тишину перед распознаванием |
| Сворачивать в трей | вкл/выкл | Крестик окна прячет приложение в трей |
| Запускать свёрнутым | вкл/выкл | Запускать сразу в трее, без окна |

## Смешанная речь (русский + английский)

Whisper — многоязычная модель, но **переключение языка внутри фразы
(code-switching) — её слабое место**: английские слова она может перевести,
транслитерировать кириллицей или потерять (особенно дистиллированная
`large-v3-turbo`). Что помогает:

1. **Начальный промпт** (`Начальный промпт` в Настройках) — задайте образец
   своей речи с английскими словами и терминами. Модель смещается в нужную
   сторону. Пример:
   > Русская речь с английскими техническими терминами: Wi-Fi, Docker, Python, GitHub, API, сервер, online.

2. **Язык = `ru`** (не `auto`) — чтобы детекция не металась между языками.
3. **Поиск (beam) = `3`–`5`** — заметно снижает «угадывание» на смешанной речи.
4. Если не помогает — используйте модель побольше (`large-v3-turbo` вместо
   `small`/`base`).

Промпт не гарантирует идеал (это ограничение самой модели), но на практике
заметно уменьшает перевод и транслитерацию английских слов.

## Производительность

На GPU (CUDA, `float16`) модель `large-v3-turbo` грузится ≈2–10 с и распознаёт
короткую фразу быстрее секунды. На CPU рекомендуется `small` или `base` с `int8`.

## Зависимости

```
customtkinter
faster-whisper
sounddevice
soundfile
numpy
pynput
pyperclip
pystray
Pillow
PySocks
```

`faster-whisper` тянет `ctranslate2`, `tokenizers`, `huggingface-hub`, `onnxruntime`, `av`.
`pystray` (вместе с `Pillow`) отвечает за значок в трее — без них приложение
работает, но крестик закрывает его, а не сворачивает. `PySocks` нужен только для
загрузки моделей через SOCKS-прокси (HTTP-прокси работает и без него).

Для сборки EXE дополнительно нужен `pyinstaller` (`requirements-build.txt`).

## Диагностика

- **«Микрофон недоступен»** — проверьте, что устройство ввода выбрано верно и не
  занято другим приложением.
- **«Модель ещё не готова…»** — дождитесь окончания загрузки или нажмите
  «Загрузить / перезагрузить модель».
- **«Не удалось скачать модель»** — проверьте интернет. Если Hugging Face
  недоступен или его CDN рвётся (анти-DPI, блокировки, «zapret»), включите
  «Прокси для загрузки моделей» и укажите `socks5://host:port` или
  `http://host:port`.
- **Текст не вставляется** — некоторые приложения (с правами администратора)
  не принимают симулированный Ctrl+V; отключите автовставку и скопируйте текст
  из лога вручную. Также убедитесь, что целевое окно в фокусе.
- **Бинд срабатывает в самой игре/оверлее** — некоторые игры перехватывают ввод
  раньше; попробуйте другую комбинацию.
