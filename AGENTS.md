# VoiceTexter — agent guide

## Рабочий процесс — ВАЖНО (читать первым)

- **Не пушить и не публиковать релизы без явного разрешения пользователя.**
  Пока пользователь не скажет «всё готово» — никаких `git push`, тегов,
  GitHub Release и пересборок ради релиза.
- Обычный режим работы: делать правки и **оставлять их локально**. Коммиты —
  только если пользователь попросит, и то без пуша.
- Перед `git push`, `git tag`, GitHub Actions или публикацией релиза —
  **спросить** пользователя. Не додумывать «на всякий случай».
- Пересборка EXE (`build_exe.bat`) — тоже не автоматически после каждой правки,
  а когда пользователь попросит проверить/собрать.
- Исключение — если пользователь прямо в текущем сообщении просит запушить
  или сделать релиз.

## Entrypoint & run

- `.\\.venv\\Scripts\\python.exe main.py` — launches the CustomTkinter GUI (`start.bat` wraps this).
- `build_exe.bat` (or `build_exe.bat onefile`) — builds `dist/VoiceTexter/VoiceTexter.exe` via `VoiceTexter.spec`; copies/links `models/` and `config.json` next to the exe.
- `setup.bat` / `setup.sh` — create `.venv`, install `requirements.txt`, copy `config.json.example` → `config.json`.
- No CLI flags, no server. The app is a single desktop GUI process.

## Architecture

Flat single-module project (no packages, no `__init__.py`):

```
main.py        — CustomTkinter GUI + app wiring (recording/transcribing/paste orchestration)
config.py      — config.json load/save, model discovery in models/, frozen-path helpers
modelstore.py  — model download from Hugging Face (stdlib urllib) + proxy (http/socks5)
recorder.py    — sounddevice microphone capture (16 kHz mono float32 numpy)
transcriber.py — faster-whisper wrapper (lazy load, device/compute resolution)
hotkeys.py     — global push-to-talk listener (pynput keyboard + mouse) and binding capture
paster.py      — clipboard + simulated Ctrl+V paste
textformat.py  — transcript cleanup before paste (capitalize first letter, final period)
tray.py        — system-tray icon (pystray); optional, callbacks marshal via the event queue
models/        — local faster-whisper model dirs (gitignored), one folder each with model.bin
assets/        — icon.png / icon.ico (generated by tools/make_icon.py)
packaging/     — Win32 version resource for the exe
VoiceTexter.spec, build_exe.bat, requirements-build.txt — PyInstaller build
```

## Key quirks

- **Threading model is the whole ballgame.** pynput listeners fire on their own
  threads; Tkinter widgets must only be touched on the main thread. So:
  - `HotkeyManager.on_activate` / `on_deactivate` (in `main.py`: `_on_activate` /
    `_on_deactivate`) run **off** the main thread. They may only read the *cached
    primitive* settings (`_model_name`, `_input_device`, `_lang`, `_beam_size`,
    `_vad`), touch the `Recorder`, and `_post()` events to `self._events`.
  - All widget reads/writes happen in `_drain_events` (polled via `after(80, …)`).
  - Settings are cached in `_sync_cached_settings()` (main thread only) — never
    read a `CTkComboBox`/`BooleanVar` from a listener or worker thread.
- **Push-to-talk semantics**: recording starts when *all* keys of the binding
  (or the mouse button) are held, and stops when *any* of them is released
  (`HotkeyManager._evaluate` recomputes on every press/release).
- **Binding format** (JSON, stored in `config.json`):
  - `{"kind": "keyboard", "keys": ["ctrl", "alt", "space"]}`
  - `{"kind": "mouse", "button": "x2"}` (mouse side buttons are `x1`/`x2`).
  Keys are normalized in `hotkeys.normalize_key` (modifiers collapse to
  `ctrl`/`shift`/`alt`/`cmd`; chars lowercased; special keys keep pynput names).
- **Binding capture** is a mode on the same listeners (`_capturing` flag):
  `begin_capture(cb)` → first non-modifier key press (with held modifiers) or the
  first mouse press finishes capture. The callback fires from the listener thread,
  so `main._on_binding_captured` only `_post`s a `("binding", …)` event.
- **Model discovery** = subdirs of `models/` containing `model.bin`
  (`config.list_models`). `large-v3-turbo` is the default. Models are load-on-demand
  in a background thread (`_preload_model`); the hotkey path refuses to record until
  the model reports loaded (`transcriber.is_loaded`).
- **Model download (modelstore.py)** = a deliberate stdlib-`urllib` downloader, *not*
  `huggingface_hub` (its Xet/httpx stack is fragile; the plain files API +
  `resolve/main/<file>` redirects are enough). `KNOWN_MODELS` maps size →
  (local folder `whisper-<size>`, HF repo); files are written as `*.part` and
  `os.replace`d only on success, so a half-downloaded `model.bin` is never mistaken
  for a complete model. Progress is a dict; `should_stop` cancels. Proxy support:
  `http(s)://` via `urllib.ProxyHandler`; `socks5(h)://` / `socks4(a)://` via PySocks
  by temporarily swapping `socket.socket` for `socks.socksocket` (guarded by a lock,
  restored in `finally`) — PySocks constants are `SOCKS5=2`/`SOCKS4=1`, NOT 4/5.
  The download runs in a worker thread; progress/done/error are `_post`ed as
  `download_progress` / `download_done` / `download_cancelled` / `download_error`.
  On success the app refreshes the model combo + tray and reloads the model.
  UI: the download control lives in Settings, but the primary entry points are the
  **first-run dialog** (`_open_download_dialog`, auto-opened when `models/` is empty)
  and the card button «⬇ Скачать модель»; progress is shown by a `CTkProgressBar`
  in both the dialog and the settings row. With no models the status is «Нет
  моделей», not a stuck «Загрузка модели…». The dialog's proxy fields are synced
  into the main `proxy_var`/`proxy_entry` on download.
- **Device/compute resolution**: `auto` → `cuda` iff `transcriber.cuda_available()`
  (loads `nvcuda.dll` / `libcuda.so`), else `cpu`; compute `auto` → `float16` on
  CUDA, `int8` on CPU. Reloading with a new device/compute swaps the model.
- **Paste** = `paster.paste_text`: copy text via pyperclip, then send the paste
  hotkey **natively on Windows via `SendInput`** (explicit `VK_CONTROL` + `VK_V`),
  with ~60 ms gaps between events and a `Shift+Insert` alternative. pynput is only
  a fallback (if `SendInput` returns 0) and the non-Windows path. The `INPUT`
  struct union must contain `MOUSEINPUT`/`HARDWAREINPUT` too, otherwise its
  `sizeof` mismatches Windows and `SendInput` silently returns 0. Optionally
  restores the previous clipboard (short sleep so the target app can read it).
  The VoiceTexter window must not steal focus — it doesn't.
- **Tray (tray.py)**: pystray runs its own thread + Win32 message loop. Menu
  actions only `_post` events; they are handled on the main thread in
  `_handle_event`: `tray_show`, `tray_toggle`, `tray_set` (`name`, `value`),
  `tray_reload`, `tray_download` (`size`), `tray_quit`. The menu has quick settings (device/compute/
  model/language radios, auto-paste/VAD checkmarks) whose checked state mirrors
  `TrayController._state`; the app pushes it via `_update_tray_state()` (called
  from `_sync_cached_settings`, so window edits stay in sync). Changing
  device/model/precision through `_apply_tray_setting` always reloads the model
  (`_reload_model`), bypassing the `preload_on_start` gate. Launched tray
  callables must stay thread-safe — never touch widgets from them. `_on_close`
  hides to tray (`withdraw()`) unless `_force_quit` or the `minimize_to_tray`
  setting is off. If the tray thread dies, `on_failed` posts `("tray_failed")`
  which restores the window.
  Without pystray/Pillow the app falls back to closing normally.
- **Frozen paths (config.py)**: `sys.frozen` → `ROOT` (and thus `models/` +
  `config.json`) is the exe's directory, so a PyInstaller build is portable;
  bundled assets are read via `config.resource_path()` from `sys._MEIPASS`.
- **Transcript formatting** (`textformat.format_transcript`) runs in
  `_handle_event("result")` before logging/pasting: it capitalizes the first
  letter and appends "." when the phrase has no final punctuation (closing
  quotes/brackets are skipped when checking, so `«Привет!»` is left alone).
- **Recording gate**: `_busy` blocks a new activation while a transcription runs;
  clips shorter than `MIN_AUDIO_SECONDS` (0.25 s) are dropped silently.
- **Shutdown**: `_on_close` saves settings, aborts recording, stops listeners and
  the tray, sets `_closing` (stops the `_drain_events` loop), then destroys the
  window. Tk may print harmless `invalid command name …` lines from pending CTk
  `after` callbacks after destroy — expected.

## Packaging (PyInstaller)

- `VoiceTexter.spec` — onedir by default; `VOICETEXTER_ONEFILE=1` builds onefile,
  `VOICETEXTER_CONSOLE=1` builds with a console (for tracebacks).
- Bundles: customtkinter data, `faster_whisper/assets` (Silero VAD onnx),
  PortAudio/libsndfile, pynput/pystray win32 backends; metadata for
  faster-whisper/ctranslate2/tokenizers/huggingface-hub/av.
- **VC runtime patch**: the spec drops the (old) `msvcp140`/`vcruntime140` that
  PyInstaller copies from the Python install and uses the ones from
  `C:\Windows\System32` instead — the old ones make `onnxruntime` crash with
  `0xC0000005` on import in the frozen app. Don't remove this.
- `models/` and `config.json` are looked up next to the exe (not bundled).

## Config

`config.json` (gitignored; template `config.json.example`) is written on every
setting change and on close. NOTE: the binding must be set on `HotkeyManager`
*and* the label rendered **before** the first `_sync_cached_settings()` in
`__init__`, otherwise the old code path saved `"binding": null`.

## Testing without a real mic/speech

- ASR smoke: load a model with `Transcriber().load(path, "auto", "auto")`, then
  `transcribe(audio_float32_16k, language=…)`. Works offline.
- **Do not put test scripts in a directory that also contains an `inspect.py`
  (or other stdlib-named file)** — Python prepends the script's dir to `sys.path`
  and shadows stdlib imports (e.g. numpy's `import inspect` breaks with
  `module 'inspect' has no attribute 'cleandoc'`).

## Dependencies

`requirements.txt` — `customtkinter`, `faster-whisper`, `sounddevice`, `soundfile`,
`numpy`, `pynput`, `pyperclip`, `pystray`, `Pillow`, `PySocks`. `faster-whisper`
pulls `ctranslate2`, `tokenizers`, `huggingface-hub`, `onnxruntime`, `av`.
`PySocks` is only needed for SOCKS-proxy model downloads.
`pyinstaller` (see `requirements-build.txt`) is build-only.
